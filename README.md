# 🏡 WanderLust - Airbnb Clone

A full-stack Airbnb Clone built using the MERN stack concepts (Node.js, Express.js, MongoDB, EJS) that allows users to explore, create, and book vacation stays.

---

## 🚀 Features

- 🔐 User Authentication (Signup/Login)
- 🔒 Authorization
- 🏠 Create, Edit & Delete Listings
- ☁️ Cloudinary Image Upload
- 🗺️ Interactive Maps (Leaflet + OpenStreetMap)
- 📍 Automatic Geocoding
- ⭐ Reviews & Ratings
- 🔍 Search Listings
- 🏷️ Category Filters
- 📅 Booking System
- 📋 My Bookings
- 📊 Host Dashboard
- 📱 Responsive UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/522ankitsingh-code/WanderLust-Airbnb-Clone.git
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
ATLASDB_URL=Your MongoDB URL

CLOUD_NAME=Your Cloudinary Cloud Name
CLOUD_API_KEY=Your Cloudinary API Key
CLOUD_API_SECRET=Your Cloudinary Secret

MAPTILER_API_KEY=Your MapTiler API Key
SECRET=Your Session Secret
```

Run the project

```bash
node app.js
```

Visit

```
http://localhost:8080
```
